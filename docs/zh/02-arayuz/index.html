    界面¶

    应用由九个菜单、两条工具栏和可停靠面板组成。本章帮助你建立对整个界面的 认知。

    整体布局¶

    ┌──────────────────────────────────────────────────────────────────┐
│ 工具栏：项目 | 格式                                               │
├───────────────┬──────────────────────────────┬───────────────────┤
│               │                              │                   │
│  标定图       │        工作区                │   AI 助手         │
│  选择         │   （标签页 / 分屏 /           │  （默认关闭）      │
│  （左侧）     │     浮动窗口）                │                   │
│               │                              │                   │
├───────────────┴──────────────────────────────┴───────────────────┤
│ 状态栏：工程、标定图、保存状态                                     │
└──────────────────────────────────────────────────────────────────┘
    • 标定图选择（左）：工程内全部标定图、分组、搜索框与收藏。自动发现的 标定图名称旁标注置信度百分比；工具栏上两个按钮可只显示已修改 （Show only modified maps）或只显示自动发现（Show only auto-detected maps）的标定图。右键列表可用 Remove duplicate maps 清理重复项。
    • 工作区（中）：每个工程是一个文档标签页，可分屏、浮动、重新停靠。 十六进制视图右侧是覆盖整个 ROM 的彩色 Overview 结构略图（见下文）。
    • AI 助手（右）：对话、工具调用记录与计划视图。
    • Checksums（右侧停靠面板，默认关闭）：列出当前 ROM 的 checksum 引擎； 提供 Verify 与 Correct & Apply（单步撤销）。状态栏右侧有 WinOLS 风格的实时 checksum 指示（见校验）。
    • 差异、调校分支、Change Recorder 与 模块 是额外的浮动/可停靠窗口。

    工程窗口内的标签页¶

    标签 内容
    Text 原始字节表：偏移、字节、ASCII/条形列
    2d ROM 波形，标定图区块以彩色矩形叠加其上
    3d 曲面图与仿真；在 Δ/Ori 模式下以红蓝热力图着色显示差值

    三个视图绑定同一份数据；一处修改立刻反映到其他视图。视图 菜单可设置默认 打开的视图。

    在 2d 标签中，单击只放置光标；双击某个标定图会打开其编辑器。编辑器底部 有 Text / 2D / 3D / 3D Sim 标签，工具栏上有 Mod / Ori / Δ / % 比较按钮；详见标定图编辑。

    Overview（结构略图）¶

    十六进制视图右侧的窄条是整个 ROM 的彩色结构略图：

    颜色 含义
    青色 Program code（程序代码）
    灰色 Empty（空白区）
    蓝色 Data（数据）
    琥珀色 Possible maps（疑似标定图）
    紫色 Recognized maps（已识别标定图）

    窄条下方有同色图例。点击或拖动窄条可把十六进制视图滚动到对应地址； 当前可见范围在略图上以浅色显示，选中的标定图以琥珀色线标记。在大容量 ROM 中，"我在哪、标定图在哪"一目了然。

    菜单¶

    项目¶

    工程管理、新建/打开/保存/另存为、A2L、OLS、KP、XDF 与 FRF/ODX 导入、ROM 与 OLS 导出、版本快照、关联 ROM、ROM/版本对比、hex 对比、从另一工程转移操作 （Accept Changes from Project…）、标定图包与 CSV 清单 导入、补丁编辑器、DTC 管理器、云端工具、经 checksum 对话框校验/修正 （Verify Checksum、Correct Checksum）、常驻 Checksums 面板 （Verify / Correct & Apply，单步撤销）、导出时自动修正 （Correct checksums on export）、ROM 签名与验证 （Sign ROM (Watermark)…、Verify Watermark）、CSV/JSON 清单 与 Excel（.xls）导出、把标定图数值批量导出为独立 CSV 文件（Export map values…）、XDF 导出、打印调校报告（Print…）、保存/加载轴配置 （Save axis profile…、Load axis profile…）、关闭工程与退出。

    知识库与维护：DTC Lookup… 从 ECU 知识库按故障诊断码搜索，并以 ROM 地址 + 说明列出结果；双击某条结果会把十六进制视图跳到该地址（data/ecukb/mtr_ecu.db， 可选）。Maintenance mode… 提供来自 data/tuningops/ 目录的数据驱动维护操作 （DPF / EGR / AdBlue / Lambda / TVA / Flaps）；详见 标定图编辑。

    批量与录制：Import directory… 导入文件夹中的全部 ROM/WinOLS 工程， Update all projects 对所有已登记工程重新运行标定图扫描。 Start/Stop recording changes 录制 ROM 编辑；Create script from changes… 把录制内容导出为 Lua 脚本或文本补丁（.mtrpatch 文本）。

    批量识别标定图：Recognize maps → add to project… 把自动发现的候选 （全部或仅高置信度）提升到标定图列表，并按 Auto-detected/Recognized、/Possible、/Low 分组归档。 Apply ECU preset… 从 data/ecupresets/ 下的预设中选择，显示其 checksum 提示，并仅填充空白的工程字段（预设可标记为 unverified 未经验证）。 调校报告通过 Export tune report as PDF… 输出为 PDF，标定图定义通过 Export A2L (DAMOS)… 输出为 .a2l 文件。

    工程管理器的 Local Projects 页提供搜索框（名称、品牌、车型、年份、 ECU、客户、路径）与点击表头的排序。新建工程属性窗口会根据 ROM 内容与 本地车辆数据库自动预填字段（品牌/ECU 建议）。当 ROM 中可读出 HW/SW 编号时， ECU 知识库（EcuKb） 也会介入：给出匹配的品牌/车型/ECU 家族建议，并在打开工程 时于状态栏提示简短的 ECU 身份（data/ecukb/mtr_ecu.db，可选）。

    编辑¶

    撤销/重做、数值 +1/−1、绝对修改、相对修改、滑块与取整限制、恢复原值、 插值、平滑、拉平、重复上一次操作（Again，F4）以及插入新的十六进制 窗口（Insert New Hexdump）。

    视图¶

    Hex 编辑器/波形/3D、数据宽度、字节序、符号、数值格式、显示差异、高度 颜色、增减列与移动原点（Move origin left/right）、Optimize value range、Show Rowmarkers、Scale 100%、Fixate Right Side、 Next/Previous Difference、Differences to Original… 对话框、浮动 3D Preview 窗口及其 3D Preview Theme 选择（Dark / Blue Mesh / Green / White）、版本对比矩阵（Version Overview…）、AI 助手、差异、 调校分支、与原版对比、缩放。Compare two maps… 可并排逐单元格对比两张 标定图；Change Recorder 面板提供开始/停止、实时变更列表以及 Lua 复制/导出。

    选择¶

    同步光标、上一张标定图、下一张标定图；此外还有单元格 / 列 / 行 / 屏幕 / 无选择（Select Cell / Column / Row / Screen / Nothing）、反选 （Invert Selection）、恢复上次选区（Restore Last Selection）、 选区移至开头 / 末尾（Selection to Start/End）、保存/加载选区 （Save/Load Selection…）、把选区转为标定图（Selection → Map…，K） 以及 Support map selection（为选中范围估算列数与原点）。

    查找¶

    地址、数值、标定图、相似文件、目录建议、注释、标记与标记导航。此外还有 Find bytes…（十六进制字节序列，支持 ?? 通配，含结果列表）、 Replace bytes…（替换全部匹配，单步撤销）以及 Next/Previous comment（在工程内注释之间导航）。

    其他¶

    工程信息、保存版本快照、自动发现标定图、可选的 MTR_PRO_BUILD 自动识别 ECU、 导入后自动扫描、处理器识别（Detect processor… —— 根据 ROM 内签名估计 CPU/系列）、命令面板、设置、自动保存、清理翻译缓存、语言选择。

    数据驱动工具：Auto-map (database)… 按 HW/SW/ECU 家族从 mapdefs.db 标定图 目录中提取标定图，通过指纹 + 数值签名对齐偏移/扇区漂移，并与盲自动检测融合； 你复核结果后加入工程（ROM 不变，无目录时仅运行盲检测）。Contribute knowledge… 为可选加入，仅在本地排队保存匿名技术摘要（无路径/PII），并可 导出为 JSONL。

    Datalog¶

    打开 log、对比 log、运行 Lua 脚本、最近文件。

    窗口¶

    恢复/保存/加载工作区布局，用 Save Layout as… 保存命名布局预设，从 Restore Layout 子菜单恢复，并用 Delete Layout… 删除；对比工程、 浮动与重新停靠、切换全部浮动窗口（Toggle floating windows）。

    帮助¶

    关于；更新检查与账号功能仅存在于商业版本。

    工具栏¶

    • 项目：新建、打开、保存、另存为、工程管理。
    • 格式：A2L、OLS、KP、XDF、CSV 导入按钮。
    • 右键工具栏并选择自定义工具栏…，可挑选显示哪些操作；选择持久保存（重启后保留）。

    快捷键¶

    快捷键 功能
    Ctrl+K 命令面板 —— 所有命令与地址均可搜索
    Ctrl+S 保存工程
    Ctrl+Z / Ctrl+Y 撤销 / 重做
    Ctrl+F 查找
    Ctrl+Tab 在已打开的工程标签间切换
    M / O / D / P 在标定图编辑器切换 Mod / Ori / Δ / % 模式
    M / W 在 Text 与 2D 中增减列数
    Ctrl+← / Ctrl+→ 在 Text 与 2D 中把原点左移 / 右移一个字节
    F / Shift+F 跳到下一 / 上一标定图
    P 开关浮动 3D Preview 窗口（工程窗口中）
    T 切换到 Text 视图
    K 把选区转为标定图（Selection → Map）
    Ctrl+B Optimize value range
    Ctrl+1 / Ctrl+2 / Ctrl+3 切换到 Text / 2D / 3D 视图
    Ctrl+Shift+F Find bytes…
    F7 / Shift+F7 下一 / 上一处差异
    F6 / Shift+F6 下一 / 上一标记
    F4 重复上次操作（Again）
    I / S 用插值 / 平滑填充选区
    % * / = + - 对选中单元格应用数学运算（会询问数值）

    QAction 快捷键可在其他 ▸ 设置 ▸ 键盘快捷键…中修改：分配已被占用的按键时会 给出冲突警告，恢复默认可回到出厂值；偏好持久保存。

    完整菜单与快捷键列表见附录 —— 菜单与快捷键。

    调整面板¶

    拖动面板可移动，可浮动为独立窗口，也可关闭。用 窗口 ▸ 保存工作区布局 保存排列。
