    设置¶

    其他 ▸ 设置 用于管理语言、主题、AI 提供方、路径与高级选项。

    语言¶

    界面语言可在 其他 ▸ 语言 中即时切换。仓库中提供六个语言包：

    tr · en · es · nl · th · zh_CN

    界面语言与标定图名称翻译是两件事：界面来自设置，标定图名称来自 其他 ▸ 翻译标定图名称。

    主题¶

    默认主题是 MRC 配色：深色底，绿色与橙色强调。ColorThemes 列表中还有其他 配色可选。

    主题切换立即生效：窗口框架、波形视图、曲线颜色、对话气泡/面板（含 guided workflow 卡片）与标定图行都会重新着色。From hexdump cursor 之类的 标签也会随之更新颜色。

    颜色¶

    设置 ▸ 颜色/主题 中的所有主题颜色均可用可视化取色器编辑。新增的 对比增量颜色（Comparison Delta Colors）分组可设置增加（暖色）/ 减少 （冷色）的增量颜色。十六进制视图右侧 Overview / minimap 条带的背景色 也在同一窗口中设置。

    用户主题可保存、重命名、删除，并可作为 .mtrtheme 文件 导入/导出。

    要自定义配色，请修改 appconfig.cpp 中的 mrcSignature() 并重新编译。

    标定图热力显示¶

    标定图编辑器表格与两个三维曲面视图共用同一套热力配色，在 设置 ▸ 标定图热力显示 中选择：

    配色 特点
    MRC 默认：深蓝 → 青绿 → 绿色 → 琥珀 → 珊瑚红
    Viridis 感知均匀，对色盲友好
    Turbo 高对比彩虹
    Grayscale 适用于打印/电子墨水的灰阶
    Classic OLS 经典蓝 → 绿 → 黄 → 红

    增量阈值决定三维增量视图中忽略多大比例的改动（以该标定图最大改动为基准， 0 % 表示全部显示）。增量视图激活时，角落会显示红/蓝差值标尺（Δ Mod−Ori）。

    键盘快捷键¶

    设置 ▸ 键盘快捷键… 对话框可编辑 QAction 快捷键：分配已被占用的按键时会给 出冲突警告，恢复默认可回到出厂值。偏好持久保存。

    新的网格与导航按键默认提供，可在同一对话框中修改：

    快捷键 功能
    M / W 在 Text 与 2D 中增减列数
    Ctrl+← / Ctrl+→ 把原点左移 / 右移一个字节
    F / Shift+F 下一 / 上一标定图
    P / T 3D Preview / Text 视图
    K Selection → Map
    Ctrl+B Optimize value range

    列布局（Text / 2D 共用网格）¶

    Text 与 2D 视图共用同一套列布局：M/W 改变列数，Ctrl+←/Ctrl+→ 改变 原点。2D 中列边界以 line-break 竖线绘制（每第 4 条为主刻度），可拖动 竖线直接改变列数。该布局在会话期间保留；选择 ▸ Support map selection 会为 选中范围找出最可能的列数与原点。

    2D 曲线的绘制样式由标定图编辑器中的 Style 选择器决定：Classic （默认）、Columns 或 WinOLS；恢复默认 也会回到 Classic。工作区 2D 视图中的 Column guides 按钮可显示/隐藏共用的列参考竖线；该偏好在会话之间 保留。

    工具栏自定义¶

    右键工具栏并选择自定义工具栏…，可挑选显示哪些操作；偏好持久保存。

    3D 预览主题¶

    视图 ▸ 3D Preview Theme 可选择浮动 3D Preview 窗口的渲染主题：Dark、 Blue Mesh、Green 与 White。选择持久保存，且独立于标定图热力 配色（是另一套曲面着色）。

    ECU 预设与工作区布局¶

    • ECU 预设： 项目 ▸ Apply ECU preset… 读取 data/ecupresets/ 下的 JSON 预设；可用 MTR_DATA_DIR 环境变量指向自定义数据根目录。预设只填充空白的 工程字段，显示 checksum 提示，并对未验证的条目给出警告。
    • 布局预设： 窗口 ▸ Save Layout as… 把当前面板排布保存为命名预设 （键 ui/layouts/<name>）；从 Restore Layout 子菜单恢复，用 Delete Layout… 删除。

    数据根目录、知识库与离线翻译¶

    • 数据根目录： data/ 下的文件（ECU 预设、ecukb/、tuningops/）从应用 旁读取；可用 MTR_DATA_DIR 环境变量更改根目录。data/ecukb/mtr_ecu.db （ECU/车辆/DTC 知识库）与 data/tuningops/*.json（维护操作）是可选的； 文件缺失时 DTC Lookup 与 Maintenance mode 会静默关闭。
    • 本地 AI 知识库（RAG）： 存在 data/ecukb/mtr_rag.db（SQLite FTS5）时， 助手会把与你最新消息最相关的知识库片段加入提示词，并向模型提供一个只读的 kb_search 工具。它完全在本地运行，不联网。没有该数据库时，助手行为与以前 完全一致。
    • 离线标定图名称 glossary： 标定图名称翻译会先查询内置的汽车缩写词表 （例如 egr、lambda、ivvt、n_max）；Fast 引擎使用 glossary + Google 链，Smart 引擎使用所选的 AI 模型。结果缓存在 mapnames 数据库中。

    Checksum（导出）¶

    启用 项目 ▸ Correct checksums on export 后，导出 ROM 时检测到的 checksum 区块会在导出的副本上自动修正（工程中的 ROM 不变）。该偏好保存在 checksum/autoCorrectOnExport 键下并在会话之间保留；关闭时会在写入前询问。

    AI 提供方¶

    字段 含义
    提供方 从列表中选择
    密钥 各提供方不同，保存在本地（Windows 上使用 DPAPI 与当前用户账户绑定加密）
    基础地址 可选，用于 OpenAI 兼容端点
    模型 从列表选择，⟳ 可刷新
    强度 发送给模型的思考预算

    模型从提供方的 /models 端点实时获取。免费/试用模型会给出提示。

    路径¶

    应用数据存放在操作系统的标准位置：

    平台 位置
    Windows %APPDATA%\MRC\MRC Tuner Studio
    Linux ~/.local/share/MRC Tuner Studio
    macOS ~/Library/Application Support/MRC Tuner Studio

    该目录包含工程、自动保存、主题、翻译缓存（mapnames.db）与对话历史。可在 设置中直接打开。

    自动保存¶

    启用自动保存后，编辑会在空闲一段时间后写入。临时文件保存在 autosave/， 崩溃时数据可恢复。

    高级¶

    • 界面缩放 —— 高 DPI 屏幕上的界面比例。
    • 字节序与数据宽度的默认值。
    • 清理翻译缓存。
    • 调试：以 MTR_DEBUG_RPC=ON 编译的版本会启用应用内 TCP 通道与文件日志， 提交问题报告时可以引用相关片段。

    配置文件¶

    设置保存在 QSettings 存储的 MRC / MRC Tuner Studio 键下。若必须手动修改， 请先关闭应用；下次启动时会读取该文件。
