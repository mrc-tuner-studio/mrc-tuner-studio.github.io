    AI 助手¶

    助手通过工具查看你工程的真实数据。它不做猜测：任何修改之前，它都会说明 将要做什么并请求你的批准。

    提供方¶

    提供方 说明
    Claude、OpenAI、Qwen、DeepSeek、Gemini、Groq 需要 API 密钥
    Ollama、LM Studio 本地运行，无需密钥
    OpenCode Zen / Go / Free 使用 OpenCode 凭据
    自定义端点 任意 OpenAI 兼容地址

    在设置（设置 ▸ AI）中选择密钥、基础地址与模型。OpenCode 的凭据可以通过 Import from opencode TUI 直接从 TUI 导入。模型列表从提供方实时获取， 用 ⟳ 按钮刷新。

    你的数据边界

    API 密钥只保存在你的机器上。选择某个提供方后，对话内容与工具结果会发送 给该提供方。敏感工程请使用本地提供方（Ollama / LM Studio）。

    权限模式¶

    模式 行为
    询问 每个写入类工具都会弹出审批卡片。默认且推荐。
    自动 不弹审批卡片，但校验层依然生效。
    计划 写入类工具被锁定，模型只能提出计划。

    工具（共 61 个）¶

    分为五组：

    发现 —— 标定图搜索、按名列出、标定图属性、坐标轴、分组、统计。

    读取 —— 当前值与原厂值、原始 ROM 读取、相似性搜索、异常检测、形状分析。

    写入 —— 整图填充、区域写入、缩放、偏移、限幅、平滑、表达式应用、复制 标定图、撤销。

    管理 —— 版本快照、关联 ROM 操作、注释、台架结果。

    计划 —— plan_start、plan_propose、plan_list、plan_remove、 plan_review、plan_finalize、plan_apply。

    计划优先流程¶

    大改动请把助手切换到计划模式。模型会依次：

    1. plan_start —— 开启会话，创建 mrc_plan.json 与 plan.md。
    2. plan_propose —— 为每处改动加入带理由的提案。
    3. plan_review —— 列出提案，便于你删去不需要的部分。
    4. plan_finalize —— 冻结计划，写入工具仍保持锁定。
    5. plan_apply —— 仅在 confirm=true 且经你批准后执行。

    应用在执行前会创建快照，并且只有通过下列检查才会写入任何一个字节：

    • 缩放与字节序校验，
    • 物理值范围限制，拒绝 NaN / 无穷值，
    • 拒绝 0.5–3.0 之外的缩放系数，
    • 标定图尺寸与目标 ROM 大小是否匹配。

    示例请求¶

    在这份 ROM 中找到催化器监测标定图并把阈值清零。
把燃油泵标定图的流量提高 8%，先出计划。
把喷射标定图的高转速区间平滑处理。

    第一条会写入（需批准），第二条在计划模式下进行，第三条只涉及单张标定图。 请求写得越具体，结果越便于审查。

    标定图名称翻译¶

    其他 ▸ 翻译标定图名称 可把标定图名称与描述翻译到目标语言。引擎链为 Google → Google (Chrome) → MyMemory，结果缓存在 mapnames 数据库中。

    实时预览表显示 原名 | 译文 两列，译文列可直接编辑。不满意的结果可用 其他 ▸ 清理翻译缓存 删除。

    对话历史¶

    对话按工程保存，重新打开工程时恢复。历史面板可回到之前的会话。

    限制¶

    • 助手只能访问当前打开工程的数据；不会在文件系统中随意浏览。
    • 写入工具无法绕过校验层。
    • 它无法保证通过安全或排放测试 —— 不测量就不要下结论。
