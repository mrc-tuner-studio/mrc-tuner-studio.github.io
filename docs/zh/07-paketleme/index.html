    打包¶

    在一个 ROM 上做一次改动很容易，在十个 ROM 上重复同样的改动却很麻烦。打包把 你的修改集中到一个文件，以便应用到其他 ROM 版本。

    两种格式，两种用途¶

    格式 内容 适用场景
    .mtrpack 标定图名称、地址、缩放与新数值 把工作迁移到其他 ROM 版本
    .mtrpatch 标定图单元格补丁与可选的原始字节补丁 精确重复同一处改动

    标定图包（.mtrpack）¶

    导出

    1. 选择 项目 ▸ 导出标定图包。
    2. 勾选要包含的标定图。
    3. 保存为 .mtrpack 或 CSV。

    导入并应用

    1. 项目 ▸ 导入标定图包 选择文件。
    2. 在列表中检查标定图。
    3. 点击应用到选中的 ROM。

    匹配分三步：显式地址、名称、包内记录的地址。尺寸不匹配与字节序差异会作为 警告提示，但仍可继续应用。

    ROM 补丁（.mtrpatch）¶

    补丁是可编辑的 JSON 文档。除标定图单元格补丁外，还可能包含标定图之外的 原始字节补丁。

    注意： 原始字节改动（例如 ECU 专有的 checksum/CRC 区域）只对同一 软件版本与同一基础 ROM 有效。套用到不同的基础 ROM 会产生错误的 checksum。 这种情况下请选择"仅应用标定图"。

    应用流程

    1. 用 项目 ▸ 补丁编辑器 打开补丁。
    2. 按名称与地址匹配标定图；CRC 不符是警告而非错误。
    3. 大型补丁要求输入 APPLY 以确认。
    4. 应用会提示创建 "Before patch: …" 版本快照。
    5. 补丁结果 窗口汇总干净应用、带警告与失败的标定图数量。

    标定图清单（CSV / JSON）¶

    两个不同的 CSV 功能，请勿混淆：

    • 标定图清单 —— 名称与地址，也可导出为 JSON，适合外部工具生成的清单。
    • CSV 数据清单 —— 某一张标定图单元格的纯文本导入导出。

    调校报告（HTML）¶

    项目 ▸ 调校报告 把改动写成可读的 HTML 文档：旧值与新值、标定图地址、备注。 适合交付客户或留存记录。

    其他导出¶

    用途 文件
    WinOLS 工程 .ols
    TunerPro 定义 .xdf
    标定图清单 .csv、.json
    报告 .html
    主题共享 .mtrtheme

    打包纪律¶

    1. 一个包只做一件事（"Stage 1 —— 低转速供油标定图"）。
    2. 写清楚每个包存在的原因。
    3. 先在刷写后的 ROM 上测试，再上车实测。
    4. 把包纳入版本控制：总有一天你会需要知道自己在什么时候用了哪个包。
