    MRC Tuner Studio¶

    把原始字节变成有意义的标定图的开源 ECU 标定工作站。

    本手册讲解从安装 MRC Tuner Studio 到完成第一次标定所需的全部内容。土耳其语是 默认版本，英文与中文可从页首的语言菜单切换。

    这个程序做什么¶

    ECU 的闪存里有成千上万张标定图。每一张标定图本质上只有三项信息：在哪里 （地址）、有多大（尺寸）、如何换算（缩放）。MRC Tuner Studio 依据这三项 信息把字节换算成物理单位（bar、°C、mg/stroke），以表格形式呈现并允许编辑。

    整个流程可以概括为一句话：

    ROM → 标定图 → 编辑 → 校验 → 打包

    建议的第一步¶

    1. 打开一个工程。 项目 ▸ 新建工程，选择你的 ROM 转储。
    2. 有 A2L 就导入。 定义文件能锁定地址与缩放，结果最可靠。
    3. 保存前先做快照。 项目 ▸ 版本快照 让你随时回到任意时刻。
    4. 写入前先校验。 项目 ▸ 校验 checksum，必要时执行 修正 checksum。
    5. 把改动打包。 若要把同一改动带到其他 ROM，导出 .mtrpatch 或 .mtrpack。

    安全与法规

    发动机软件改动会直接影响安全与排放测试。改动前请先测量，并确认符合当地 法规。MRC Tuner Studio 只是让编辑更方便，责任仍在你。
