    Automation¶

    Instead of doing repetitive work by hand you can script it: batch edits, exports, comparisons and even simple HTTP requests.

    Command palette¶

    Ctrl+K — every command in the application appears in one searchable list. Typing part of a command name is enough. It is the fastest way to find an action without knowing the menus.

    The palette also supports direct address jumps: typing 0x1A400, $1A400 or a bare hex value puts an Address: Jump to 0x… entry at the top of the list; Enter jumps the active project's Hex and 2d views to that address.

    Map search results draw a small curve sparkline sampled from the ROM data for each map, so you can see its shape without opening it.

    Lua engine¶

    The application embeds Lua 5.4 and binds the C++ API to scripts through sol2. Run a script with Datalog ▸ Run Lua Script.

    What is available¶

    • read project properties,
    • read and write bytes, convert addresses,
    • search maps, find and replace, import and export,
    • add comments, similarity search,
    • HTTP requests,
    • open dialogs, call the interface.

    Security limits¶

    Scripts run on a worker thread and return to the UI only through controlled calls. The engine disables:

    • os.execute, os.exit, io.popen, package.loadlib, dofile, loadfile, load
    • os.remove, os.rename and os.tmpname outside approved paths

    Running a new script for the first time requires confirmation, and the trust decision is stored with the script's SHA-256 fingerprint.

    Example¶

    -- List every map whose name contains "KRKTE"
local maps = searchMaps("KRKTE")
for _, m in ipairs(maps) do
  Log(m.name .. " @ " .. m.address)
end

    Known gaps¶

    The Lua checksum DSL, projectImportCsvJson, projectMail, some WinOLS-specific rights and vehicle-data operations and encrypted .luax loading are not implemented.

    Debug RPC (developer channel)¶

    Builds with MTR_DEBUG_RPC=ON open a line-delimited JSON channel on 127.0.0.1:48714. The channel is meant for automation and testing; it is disabled in Release builds.

    Map-aware writing¶

    The older apply_edit command works on a byte range and uses the display setting's cell size — on a 16-bit map it truncated the value to a single byte and left the high byte at its stale ROM value. The new set_map_values command uses the map's own cell size, byte order and signedness:

    {"cmd":"set_map_values","args":{"sub":0,"map":"Boost target","value":3500,"absolute":true}}

    The response contains the raw bytes that were written, so the write can be verified:

    {"ok":true,"result":{"raw":"F5 24","bytesWritten":"F5 24","dataSize":2,
 "byteOrder":"little-endian","signed":true,"cellCount":1}}

    If the value does not fit the cell the command returns an error — there is no silent truncation:

    {"ok":false,"error":"value 40000 does not fit in a 2-byte signed cell"}

    Pass "clamp":true to clamp instead; the result then reports clamped:true.

    Repairing a map¶

    Command What it does
    map_info The full map record: dataSize, signed, byteOrder, effectiveByteOrder, scaling
    set_map_byte_order Changes one map's byte order; the global setting is untouched
    set_map_scaling Fixes one map's scaling (coeffA, offset, unit)
    action {"trigger":"m_actSave"} Saves the project

    set_map_byte_order and set_map_scaling are persistent: they are written to the project file. map_info additionally reports the project byte order (projectByteOrder) and the map's own byte order (mapByteOrder) separately; when they differ, the map is read with its own order.

    Datalog¶

    Datalog ▸ Open Log opens CSV recordings; pick channels from the tree and read the time-series graphs. Datalog ▸ Compare Logs overlays two recordings.

    Three source formats are recognised automatically:

    • Vehical — three header rows (name / description / unit), first column Time in milliseconds.
    • Autotuner — single header row starting with timestamp, units embedded in the column names as (unit).
    • VCDS (Ross-Tech) measuring-block logs — every measuring group has its own TIME/STAMP column and samples on its own clock. The groups are merged onto one time axis by linear interpolation, so a VCDS export can be compared against a map directly. European exports write decimal commas; both 0.96 and 0,96 are accepted.

    A practical order of preference for bulk work¶

    1. Does an external tool already do it?
    2. Is the application's packaging feature enough?
    3. Does the command palette solve it in one step?
    4. Only then write a Lua script.

    Before you script something¶

    1. Do not repeat a manual job: package it (see Packaging).
    2. Write a script only for genuinely repetitive multi-step work.
    3. Keep scripts in version control and comment which map addresses they touch.

    MCP server for external AI agents¶

    To delegate automation tasks to external AI agents (Claude Desktop, Claude Code, OpenCode, Cursor, etc.) or automate operations via the command line, use the built-in Model Context Protocol (MCP) server. For details and tool listings, see AI assistant — MCP server.
