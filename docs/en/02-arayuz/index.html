    Interface¶

    The application consists of nine menus, two toolbars and dockable panels. This chapter gives you the map of the screen.

    Overall layout¶

    ┌──────────────────────────────────────────────────────────────────┐
│ Toolbar: Project | Format                                        │
├───────────────┬──────────────────────────────┬───────────────────┤
│               │                              │                   │
│  Map          │      Workspace              │   AI Assistant    │
│  Selection    │      (tabs / splits /        │   (hidden by      │
│  (left)       │       floating windows)      │    default)       │
│               │                              │                   │
├───────────────┴──────────────────────────────┴───────────────────┤
│ Status bar: project, map, save state                             │
└──────────────────────────────────────────────────────────────────┘
    • Map Selection (left): all maps of the project, folder groups, a search box and starring. Auto-detected maps carry a confidence % next to their name; two toolbar buttons filter the list to modified maps only (Show only modified maps) or auto-detected maps only (Show only auto-detected maps). Right-clicking the list offers Remove duplicate maps to clean up duplicates.
    • Workspace (centre): every project opens as a document tab. Tabs can be split, floated and re-docked. Right of the hex view sits a colour-coded Overview minimap of the whole ROM (see below).
    • AI Assistant (right): chat, tool traces and the plan view.
    • Checksums (right dock, hidden by default): lists the active ROM's checksum engines; Verify and Correct & Apply (a single undo step). A WinOLS-style live checksum readout sits at the right of the status bar (see Verification).
    • Differences, Tuning Branches, Change Recorder and Module are additional floating or dockable windows.

    Tabs inside a project window¶

    Tab Shows
    Text Raw byte table: offset, bytes, ASCII/bar column
    2d ROM waveform with colour-coded map blocks drawn on top
    3d Surface plot and simulation; in Δ/Ori mode it paints the difference as a red-blue heat map

    All three views are bound to the same data; a change in one appears instantly in the others. View selects which view opens by default.

    In the 2d tab a single click only places the cursor; double-clicking a map opens that map's editor. The editor's bottom row has Text / 2D / 3D / 3D Sim tabs and its toolbar has the Mod / Ori / Δ / % comparison buttons; see Map editing for details.

    Overview (structure map)¶

    The narrow strip right of the hex view is a colour-coded minimap of the whole ROM:

    Colour Meaning
    Teal Program code
    Grey Empty area
    Blue Data
    Amber Possible maps
    Violet Recognized maps

    A legend in the same colours sits below the strip. Clicking or dragging the strip scrolls the hex view to that address; the currently visible hex range is washed light and the selected map is marked with amber lines. That answers "where am I, where are the maps" at a glance in large ROMs.

    Menus¶

    Project¶

    Project manager, new / open / save / save-as, A2L, OLS, KP, XDF and FRF/ODX import, ROM and OLS export, version snapshots, link ROM to project, ROM and version comparison, hex comparison, operation transfer from another project (Accept Changes from Project…), map pack and CSV list import, patch editor, DTC Manager, Cloud Tools, checksum verification/correction through the checksum dialog (Verify Checksum, Correct Checksum), the persistent Checksums panel (Verify / Correct & Apply, a single undo step), automatic correction at export (Correct checksums on export), ROM signing and verification (Sign ROM (Watermark)…, Verify Watermark), CSV/JSON list and Excel (.xls) export, bulk export of map values into separate CSV files (Export map values…), XDF export, printing the tuning report (Print…), saving and loading axis profiles (Save axis profile…, Load axis profile…), close project and exit.

    Knowledge base and maintenance: DTC Lookup… searches the ECU knowledge base for a diagnostic trouble code and lists the result with its ROM address and description; double-clicking a result jumps the hex view to that address (data/ecukb/mtr_ecu.db, optional). Maintenance mode… offers data-driven maintenance operations (DPF / EGR / AdBlue / Lambda / TVA / Flaps) from the data/tuningops/ catalogue; see Map editing for details.

    Batch work and recording: Import directory… imports every ROM/WinOLS project in a folder and Update all projects re-runs the map scanner on all registered projects. Start/Stop recording changes records ROM edits; Create script from changes… exports that recording as a Lua script or a text patch (.mtrpatch text).

    Bulk map recognition: Recognize maps → add to project… promotes auto-detected candidates (all or high-confidence only) into the map list and files them under Auto-detected/Recognized, /Possible and /Low folders. Apply ECU preset… picks from the presets under data/ecupresets/, shows their checksum hint and fills empty project fields only (presets can be marked unverified). The tuning report is written to PDF with Export tune report as PDF… and map definitions to .a2l with Export A2L (DAMOS)….

    The project manager's Local Projects tab has a search box (name, brand, model, year, ECU, client, path) and sorting by clickable headers. The new project properties dialog prefills its fields from the ROM contents and the local vehicle database (brand/ECU suggestions). When the ROM exposes HW/SW numbers the ECU knowledge base (EcuKb) steps in too: a matching brand/model/ECU family is suggested and a short ECU identity line is announced in the status bar when a project opens (data/ecukb/mtr_ecu.db, optional).

    Edit¶

    Undo / redo, value +1 / −1, absolute change, relative change, slider and round limits, restore original, interpolate, smooth, flatten, repeat the last operation (Again, F4) and insert a new hex window (Insert New Hexdump).

    View¶

    Hex editor / waveform / 3D map, data width, byte order, sign, number format, show differences, height colours, more/fewer columns and origin shifting (Move origin left/right), Optimize value range, Show Rowmarkers, Scale 100%, Fixate Right Side, Next/Previous Difference, Differences to Original… dialog, the floating 3D Preview window with its 3D Preview Theme choice (Dark / Blue Mesh / Green / White), the version comparison matrix (Version Overview…), AI Assistant, Differences, Tuning Branches, differences versus original, and zoom. Compare two maps… compares two maps side by side, cell by cell; the Change Recorder panel offers start/stop, a live change list and Lua copy/export.

    Selection¶

    Synchronise cursors, previous map, next map; plus cell / column / row / screen / nothing selection (Select Cell / Column / Row / Screen / Nothing), inverting the selection (Invert Selection), restoring the last selection (Restore Last Selection), moving the selection to the start / end (Selection to Start/End), saving and loading selections (Save/Load Selection…), turning a selection into a map (Selection → Map…, K) and Support map selection (estimates the column count + origin for the selected range).

    Find¶

    Address, value, map, similar files, catalogue suggestions, comments, markers and previous/next marker navigation. Also Find bytes… (hex byte sequence with ?? wildcard support and a results list), Replace bytes… (replaces every match, one undo step) and Next/Previous comment (navigate comments in the project).

    Miscellaneous¶

    Project info, save version snapshot, auto-detect maps, optional MTR_PRO_BUILD auto-detect ECU, auto-scan on import, processor detection (Detect processor… — CPU/family estimate from ROM signatures), command palette, settings, auto save, clear translation cache and language selection.

    Database-backed tools: Auto-map (database)… extracts maps from the mapdefs.db catalogue by HW/SW/ECU family, aligns offset/sector shifts through a fingerprint + value signature and blends them with blind auto-detection; you review the results and add them to the project (the ROM is unchanged, and with no catalogue only blind detection runs). Contribute knowledge… opt-in queues only an anonymous technical summary (no paths/PII) locally and exports it as JSONL.

    Datalog¶

    Open log, compare logs, run Lua script and recent files.

    Window¶

    Restore / save / load workspace layout, save named layout presets with Save Layout as…, restore them from the Restore Layout submenu and remove them with Delete Layout…; compare projects, float and re-dock, toggle all floating windows (Toggle floating windows).

    Help¶

    About; update checking and account actions exist only in the proprietary build.

    Toolbars¶

    • Project: new, open, save, save as, project manager.
    • Format: A2L, OLS, KP, XDF and CSV import buttons.
    • Right-click a toolbar and choose Customize Toolbar… to pick which actions are visible; the choice is persistent (survives restarts).

    Keyboard¶

    Shortcut Action
    Ctrl+K Command palette — every command and address is searchable
    Ctrl+S Save project
    Ctrl+Z / Ctrl+Y Undo / redo
    Ctrl+F Find
    Ctrl+Tab Cycle open project tabs
    M / O / D / P Mod / Ori / Δ / % modes in the map editor
    M / W Widen / narrow the columns in Text and 2D
    Ctrl+← / Ctrl+→ Shift the origin one byte left / right in Text and 2D
    F / Shift+F Go to the next / previous map
    P Toggle the floating 3D Preview window (in the project window)
    T Switch to the Text view
    K Turn the selection into a map (Selection → Map)
    Ctrl+B Optimize value range
    Ctrl+1 / Ctrl+2 / Ctrl+3 Switch to the Text / 2D / 3D view
    Ctrl+Shift+F Find bytes…
    F7 / Shift+F7 Next / previous difference
    F6 / Shift+F6 Next / previous marker
    F4 Repeat the last operation (Again)
    I / S Fill the selection by interpolation / smooth
    % * / = + - Apply maths to selected cells (a value is asked for)

    QAction shortcuts are edited in Miscellaneous ▸ Settings ▸ Keyboard Shortcuts…: a conflict warning appears when a key is already taken, Reset to defaults restores factory values; preferences are persistent.

    See the Appendix — menus and shortcuts for the complete list.

    Rearranging panels¶

    Drag panels to move them, float them into their own window or close them. Save the arrangement with Window ▸ Save Workspace Layout.
